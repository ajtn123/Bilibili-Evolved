为「仪表盘首页」添加「AI 助手」标签页。支持连续对话，也可以请助手请求 B 站接口。

在 Bilibili Evolved 的「AI 模型配置」中添加支持对话的模型，再在标签页中选择它。密钥由 Bilibili Evolved 管理。清空对话或刷新页面会移除记录。

助手会结合你的消息、近期对话和仪表盘的接口参考提出请求。默认逐次批准，每次都可以查看请求方法和完整地址。可在输入框下方改为自动批准 GET 或全部请求，选择会在离开标签页后重置。标签页会显示返回的内容，并将其发送给所选模型。过长的正文会截断。拒绝会告知模型，取消会结束本轮对话。

助手可以提出 bilibili.com 及其子域名的 HTTPS 请求。浏览器会按其规则携带 B 站登录凭据，接口返回的内容可能包含账号资料。
